# Формат `mod-packs.json`

Файл лежит в `%APPDATA%\Factorio\mods\mod-packs.json`. Он создаётся при первом изменении пакетов и не удаляется при деинсталляции модификации.

```json
{
  "format": 1,
  "selected": "Krastorio run",
  "packs": [
    { "name": "Krastorio run", "mods": ["Krastorio2", "Krastorio2Assets", "flib", "space-age"] },
    { "name": "Vanilla Space Age", "mods": ["elevated-rails", "quality", "space-age"] }
  ]
}
```

| Поле | Тип | Смысл |
|---|---|---|
| `format` | число | Версия формата, сейчас `1`. Файл другой версии считается нечитаемым. |
| `selected` | строка или `null` | Выбранный пакет. Если пакета с таким названием нет, выбор сбрасывается. |
| `packs` | массив | Пакеты в порядке названий без учёта регистра. |
| `packs[].name` | строка | Название пакета, без пробелов по краям, уникальное без учёта регистра. |
| `packs[].mods` | массив строк | Внутренние имена модов (как в `mod-list.json`), отсортированы, без повторов, без `base`. |

При чтении модификация нормализует данные: обрезает пробелы в названиях, отбрасывает пакеты с пустыми или повторяющимися названиями, удаляет `base`, дубликаты и пустые имена модов.

**Запись** атомарная. Сначала пишется `mod-packs.json.tmp` в той же папке и сбрасывается на диск, затем он заменяет основной файл. Если игра упадёт во время записи, останется целый старый или целый новый файл.

**Повреждённый файл** (не JSON, другая версия формата, неверная структура) не перезаписывается при чтении. Рядом сохраняется копия `mod-packs.json.broken-ГГГГММДД-ЧЧММСС`, а пользователь видит сообщение. Список пакетов при этом пуст, и основной файл перезапишется только тогда, когда пользователь изменит пакеты.

Пример выше проверяется тестом `tests/pack_file_tests.cpp` («documented example…»).
